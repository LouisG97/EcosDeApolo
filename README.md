# Ecos de Apolo — versión rediseñada

## Archivos principales
- `index.html`: página de inicio.
- `tgwdlm.html`: página de la producción *El hombre al que no le gustaban los musicales*.
- `styles.css`: sistema visual compartido y estilos adaptables.
- `scripts.js`: animaciones accesibles, año automático y galería ampliable.
- `img/`: recursos originales conservados.
- `img/optimized/`: copias WebP optimizadas para el sitio; los originales no se modificaron.

## Publicación
Mantiene HTML, CSS y JavaScript y conserva Bootstrap 5 para la navegación adaptable. Las fuentes, Bootstrap y los iconos se cargan desde CDN; la conexión a internet es necesaria para esos recursos. `CNAME` se conserva para mantener la configuración del dominio de GitHub Pages.

## Notas que requieren verificación antes de publicar
1. El enlace visible de WhatsApp del sitio original usa `+526442041328`, mientras que el JavaScript antiguo contiene otro número. La nueva versión conserva el número del enlace visible; confirma que siga siendo el correcto.
2. Se conservaron los nombres, personajes y perfiles sociales tal como aparecen en el HTML de origen; conviene validarlos con la ficha de producción.
3. Los textos de la compañía y la sinopsis fueron aprobados durante la revisión del rediseño.
4. `styles2.css` y el JavaScript de reservaciones fotográficas se retiraron de los archivos activos porque no corresponden a las dos páginas del sitio. Los originales permanecen en el archivo RAR de origen.

## Pruebas recomendadas antes de publicar
Abrir ambas páginas en móvil y escritorio; verificar menú, correo, Instagram, WhatsApp, perfiles del elenco, galería y carga de recursos externos.
